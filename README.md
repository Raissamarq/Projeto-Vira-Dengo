# Projeto-Vira-Dengo# 🐾 ViraDengo

## 📌 Sobre o Projeto

O **ViraDengo** é uma plataforma web responsiva que conecta ONGs, tutores, voluntários e profissionais do universo pet.
O objetivo é facilitar a colaboração e o apoio a causas animais, promovendo adoções, doações, campanhas e serviços de forma acessível e organizada.

---

## 🎯 Problema

Muitas ONGs e protetores independentes enfrentam dificuldades para:

- Divulgar campanhas e necessidades
- Encontrar voluntários
- Receber doações de forma eficiente
- Conectar-se com pessoas dispostas a ajudar

---

## 💡 Solução

O ViraDengo surge como um ponto de conexão, permitindo que:

- ONGs publiquem campanhas e necessidades
- Usuários façam doações de itens
- Voluntários encontrem oportunidades para ajudar
- Profissionais ofereçam serviços voltados ao universo pet

---

## 🚀 Funcionalidades

- 📢 Publicação de campanhas (ex: vacinação, adoção)
- 🎁 Doação de itens
- 🤝 Cadastro de voluntários
- 💬 Sistema de interesse e contato (chat)
- 🧑 Perfil de usuário (tutor, voluntário ou ONG)
- 📰 Feed com diferentes tipos de postagens

---
